# Willkommen

Du hältst den vollständigen Praxiskurs zu [Ai_Framework](https://github.com/thorstenkloehn/Ai_Framework)
in Händen — einem KI-Framework für Rust, das wir in diesem Buch von der ersten Zeile bis
zur veröffentlichbaren Version 0.1.0 gemeinsam bauen.

Dieser Kurs setzt **nichts** voraus. Du musst weder Rust noch überhaupt eine
Programmiersprache kennen. Wir beginnen bei "Was ist eine Variable?" und enden bei einem
eigenständigen, testbaren, dokumentierten Rust-Crate mit LLM-Anbindung, Agenten, Retrieval
und einer REST-API.

Zwei Dinge machen diesen Kurs anders als die meisten Tutorials:

1. **Wir bauen ein echtes Projekt, keine Spielzeug-Beispiele.** Jede Lektion bringt das
   Framework aus [github.com/thorstenkloehn/Ai_Framework](https://github.com/thorstenkloehn/Ai_Framework)
   einen nachvollziehbaren Schritt weiter. Am Ende jeder Phase steht ein Release, den du
   selbst als Git-Tag setzt.
2. **Du tippst den Code selbst.** Dieses Buch ist kein Ort zum Copy-Paste. Wir besprechen
   Code, erklären ihn Zeile für Zeile, zeigen bewusst provozierte Compilerfehler — aber
   getippt, kompiliert und getestet wird bei dir, in deinem eigenen VS Code.

Wenn du bereit bist: [Los geht's mit der Einleitung](README.md).
